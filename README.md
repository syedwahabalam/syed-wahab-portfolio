# Syed Wahab Alam — Personal Portfolio

A responsive personal portfolio built with HTML, Tailwind CSS (CDN), and a small amount of custom CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. An internet connection is required for the Tailwind CDN and Google Fonts.

## Personalise before submission
1. Add your own portrait photo to the `assets` folder and name it `profile.jpg`.
   - Recommended: a clear, professional portrait in JPG format.
   - The page currently shows a WA placeholder if the image is missing.
2. Review your phone number, email, website, LinkedIn profile, job titles, dates, and project descriptions.
3. Add screenshots for your academic projects if you have them.
4. Your GitHub profile is linked in the Contact section and footer: https://github.com/syedwahabalam. Add individual repository links to project cards only when you want to feature specific repositories.
5. The contact form is front-end only. It opens the visitor's email application; it does not store or send messages through a server.

## Technologies
- HTML5
- Tailwind CSS via CDN
- Custom CSS
- Vanilla JavaScript

## Sections
Home, About, Technology Interests & Writing, Skills, Projects, Experience, Education, Contact, and Footer. The interests and article links incorporate material from syedwahabalam.com.
